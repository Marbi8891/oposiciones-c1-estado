# Estado y hoja de ruta

## Objetivo

Mantener una herramienta personal estable para preparar Administrativo del Estado C1, priorizando la fidelidad a los materiales de estudio, la trazabilidad de las referencias legales y la protección de los datos locales.

## Prioridad 1: distribución reproducible

- [ ] Decidir qué versión exacta se publicará y etiquetarla.
- [ ] Comprobar que el paquete incluye todos los recursos necesarios.
- [ ] Publicar un ZIP sin documentos de academia que no tengan permiso de redistribución.
- [ ] Probar el proceso de descarga, descompresión y apertura en un Mac limpio.

## Prioridad 2: calidad

- [ ] Ejecutar la lista de comprobación de `PRUEBAS_Y_CALIDAD.md`.
- [ ] Corregir errores de navegación y búsqueda reproducibles.
- [ ] Añadir pruebas automatizadas donde sea viable.
- [ ] Revisar teclado, contraste, ampliación y lectores de pantalla.

## Prioridad 3: trazabilidad del temario

- [ ] Inventariar los temas y sus versiones.
- [ ] Detectar temas ausentes y duplicados.
- [ ] Crear un registro de comprobación normativa por tema.
- [ ] Contrastar el programa con la convocatoria oficial aplicable.

## Prioridad 4: copias y recuperación

- [ ] Comprobar exportación e importación de progreso.
- [ ] Documentar cómo restaurar una copia.
- [ ] Evaluar una exportación periódica manual antes de plantear sincronización remota.

## Criterio de finalización

Una tarea se considera terminada cuando se ha probado y documentado. No presentar como implementadas funciones que solo estén previstas. No añadir autenticación, sincronización o ejecución de código sin revisar antes sus implicaciones de seguridad y privacidad.
