# Contribuir

Este proyecto es principalmente de uso personal. Antes de proponer cambios, describe el problema que resuelven y cómo se comprobará el resultado.

## Cambios recomendados

- Mantener el contenido original de los apuntes identificable y separado de las notas añadidas.
- No declarar como verificada una norma sin indicar la fuente oficial y la fecha de consulta.
- Evitar dependencias innecesarias si una solución sencilla en HTML, CSS y JavaScript basta.
- No incorporar credenciales, datos personales ni material de terceros sin permiso.
- Actualizar la documentación y el registro de cambios cuando cambie el comportamiento.

## Antes de enviar un cambio

1. Describe el comportamiento actual y el esperado.
2. Incluye pasos para reproducir el problema, si procede.
3. Ejecuta las comprobaciones pertinentes de `PRUEBAS_Y_CALIDAD.md`.
4. Indica qué pruebas no se han podido ejecutar.
5. No incluyas archivos de academia ni exportaciones personales en la propuesta.
