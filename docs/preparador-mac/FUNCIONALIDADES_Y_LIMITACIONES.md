# Funcionalidades y limitaciones

Este documento describe el alcance previsto de la versión personal. No debe interpretarse como una certificación de que cada función haya superado pruebas completas.

## Alcance previsto

- Organización del temario por bloques y temas.
- Consulta de la aplicación desde un navegador en macOS.
- Biblioteca de documentos e índice de texto en el paquete completo.
- Seguimiento de sesiones y progreso, de acuerdo con las funciones implementadas en la versión distribuida.
- Exportación o importación de datos, cuando esté habilitada en la versión concreta.

## Limitaciones conocidas

- No es una aplicación nativa de macOS ni una plataforma multiusuario con cuentas.
- El almacenamiento del navegador puede borrarse y no se sincroniza automáticamente entre equipos.
- El comportamiento de la búsqueda de archivos locales varía según el navegador; puede requerir un servidor HTTP local.
- El catálogo puede contener temas sin documento, archivos repetidos o versiones de distinta fecha.
- No se debe asumir que los apuntes reflejan siempre la normativa vigente o la versión aplicable a una convocatoria concreta.
- No se garantiza la accesibilidad completa con todos los lectores de pantalla, tamaños de pantalla o métodos de entrada hasta completar una auditoría específica.
- No se debe considerar seguro ejecutar código de terceros dentro de esta aplicación sin un diseño y una evaluación de seguridad específicos.

## Fuera de alcance por ahora

- Sincronización en la nube, autenticación y recuperación remota de cuenta.
- Aplicación iOS/Android nativa.
- Validación jurídica automática de todos los temas.
- Garantía de cobertura completa del programa oficial o de aprobación del examen.

Las funciones deben comprobarse sobre la versión concreta antes de anunciarse como terminadas.
